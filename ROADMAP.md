# Roadmap

## Phase 0 — Research (done as docs)
- Research report, feasibility matrix, threat model, MVP spec.

## Phase 1 — MVP (current)
- RPC endpoint configuration.
- RPC health + latency monitoring for a verified endpoint.
- Basic responsive dashboard.
- Protocol proposal templates (RFC).
- Launch readiness checker using documented inputs.
- Unit + integration tests + CI.

## Phase 2 — After MVP works
- Transaction inspector (documented data sources).
- Protocol proposal explorer.
- Launchpad analytics (available data only).
- Desktop diagnostics (independent tools only).

## Phase 3 — Optional
- AI agents (narrowly scoped, validated inputs).
- MCP server (narrowly scoped tools).
