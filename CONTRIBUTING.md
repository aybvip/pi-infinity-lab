# Contributing

## Ground rules

1. Research official docs before implementing integrations.
2. Never invent endpoints/APIs/RPC methods/smart-contract interfaces.
3. Label mock implementations clearly (`mock: true`).
4. Do not claim official support/endorsement.
5. Do not execute real token launches or transactions without explicit authorization.
6. Do not describe a project as audited/safe merely because it passed an automated scanner.

## Development

```bash
pnpm install
pnpm test
pnpm typecheck
```

## Pull requests

- Include tests.
- Update docs when behavior changes.
- Keep changes focused.
