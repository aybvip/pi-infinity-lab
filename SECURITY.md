# Security Policy

## Reporting

Report vulnerabilities privately to the maintainers. Do not open public issues for undisclosed vulnerabilities.

## Scope

This project is research/developer tooling. It is **not** audited and should not be treated as production-ready security software.

## Principles

- Server credentials stay on the backend.
- No unrestricted shell execution or arbitrary filesystem access in agents.
- No automatic mainnet transactions.
- User approval required for destructive/consequential actions.
- Do not bypass sandboxing/isolation/security controls.
